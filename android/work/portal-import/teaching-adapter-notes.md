# 1.5.3 时间字段扩展

成功 capture 可选包含 `periods:[{period,start,end}]`，仅采集已知节次表头明确显示的 1–10 节起止钟点。没有可读时段时不添加该字段。原五字段 capture 仍然有效。原生合同与纯数据解析器双重校验，不扩大主机或页面读取范围。

本地导入预览显示可选时间同步，确认之前不写入；取消勾选保留自定义时间。新夜课只有网页明确提供所需全部节次时才换算完整钟点，否则沿用已有可信本地夜课或保留待确认。全新/已清空课表不借用内置个人夜课时间。

真实现场样本没有每节钟点；扩展通过隔离 HTML 样本验证，不代表新增其它学校网页适配。

# 江苏科技大学个人课表适配器

现场依据：2026-10-11，用户自行登录学校 WebVPN 后的教务系统个人课表。实际 HTTPS 主机为 `client.v.just.edu.cn`，路径以 `/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html` 结尾。该页的 `#kbgrid_table_0` 共 14 行，第二行为“时间段、节次、星期一…星期日”；后续明确列出 1–11 节。

`teaching-fixture.json` 保存 20 个课程块的课程公开字段，不包含姓名、学号、账户、密码、验证码、Cookie、Token、登录表单值或隐藏字段。它与现场 DOM 的独立捕获 `teaching-capture.json` 一致。20 块全为已选蓝色字体；红色待筛选课程的处理由构造用例验证，尚无现场红色课程样本。

`teaching-collector.js` 是 APK 内置固定脚本，只读对应课表 DOM。它校验主机、路径、表格行数、精确星期表头、1–11 节、选中选项的可见学年/学期与第一个 h6 的学期标题。只取每个课程块的 `.title`、前 4 个 `p` 和字体 `color`；底部实践/其它课程只返回是否存在的布尔值。其它 h6（含姓名/学号）不读。成功返回 JSON 字符串；Android `evaluateJavascript` 回调需先解码外层 JSON，再解码其字符串。失败仅含固定错误码，无异常消息或页面内容。

`teaching-parser.js` 为纯数据 UMD 模块（浏览器 `window.TeachingParser`）。`normalizeCapture(capture, settings, periods, currentCourses)` 返回 `source`、`term`、`scope`、`occurrences`、`warnings`、`rejectedCount`、`unscheduledPresent`、`stats`。传给安全合并模块时仅摘取 `{source, scope, occurrences, rejectedCount}`。

教学班 code 保存为 `sourceKey`。`sourceOccurrenceId` 是由学期、教学班、星期、起止节次、周次派生的课表模式标识，学校页面没有提供真正的课次 ID；调整时间可能改变该标识，不能声称它可稳定追踪调课。安全合并器需对同教学班同周的新模式要求人工核对。

周次按逗号分段处理单双，不能对整段表达式统一套奇偶过滤。以用户已确认的第一周周一及个人 8 节时间展开日期；第 9–11 节缺少页面具体钟点，只有已有同名、同节次且唯一明确的夜课时间可复用，其他夜课标为待确认。原始同一学期已确认的夜课时间作为规范化参考保留，即使旧版中已删除、改名或调整该课，也不会把它误判为一门新待定课程重新添加；不改写当前本地课程。无具体节次的底部实践/其它课不生成课次。

验证：`node --test work/portal-import/teaching-parser.test.cjs` 共 15 项通过。真实 20 块展开成 168 次课程，与此前独立按日期读取的 portal 课表逐课程、日期、星期、节次完全相符。课程名、周次和教室均来自现场字段，完整输入、当前课程、个人课时和设置在规范化前后不变。

最终 1.1.0 的编译产物集成测试共 13 项通过，Android 16 / API36 模拟器的 9 项运行检查通过，包括原生读取按钮到预览的完整内部链路、勾选教室变更、取消不写入、备份和重启、重复导入、手工改名/调课/删除保护及 13 次补充实验保留。原始课表为 181 次，读取教务课表为 168 次，默认预览为 161 次已存在、7 次教室更新、0 次新增。七次更新均为示例电学1第 8–14 周周五第 3–4 节：由旧“示例教学楼A-101”变为教务页“示例教学楼BE-203”，需要用户逐项确认。

Android 流程使用阻断网络的课程表格 fixture，不等于验证真实学校登录或服务器可达性；尚未在用户三星 SM-S9380 / WebView153 上运行。运行记录含正式 APK 哈希，见 `android-tests/reports/runtime-result-api36.json`。
