# 数据说明

课表、课程修改、外观设置和导入确认结果保存在当前设备。更换设备时可通过本地备份迁移；首次安装从空课表开始。

教务导入需要访问学校或校园 VPN。请在学校页面完成登录，不要把密码、登录 Cookie 或学生信息发到 GitHub Issue。

DeepSeek 是可选功能，使用用户自己的 API Key。发起识别时，消息和文件内容会发送到所配置的 API 服务；费用和数据处理规则取决于该服务。API Key 留在当前设备，源码和安装包不提供公共密钥。

公开源码中的解析样本已改为示例教师、课程和班级。仓库不包含发布签名、密码、用户备份、研究用实拍照片和航拍视频。

反馈问题时，请遮盖姓名、学号、联系方式、API Key 和教务登录信息。
